## Неточности и оговорки

- AC: выпуклость не гарантирует ни единственности минимума (дубли признаков), ни его существования (логрегрессия на разделимых данных).
- T: номера глав MIT 6.042J различаются между изданиями, заменены на названия глав; формула роста prefill уточнена (линейные слои ×4, внимание ×16).
- L: добавлен оптимальный порог для калиброванной оценки C_FP / (C_FP + C_FN).
- X: NDCG 0.61 верен только для выигрыша 2^rel − 1, для линейного 0.65.
- P: автопоиск не «меняет по одному», а работает как факторный план.
- Q: у XGBoost с версии 1.6 есть встроенные категории.
- N: лемматизация убрана из «минимальной нормализации» для сравнения строк.
- AA: биграммы частично спасают простое отрицание.
- S: размерности эмбеддеров были перепутаны (четыре числа на три модели).
- J: токенизация русского — 2–4 токена на слово и ×1.5–3 к английскому, в зависимости от токенизатора.
- R: RRF складывает обратные ранги, а не позиции.
- V: гипотетический ответ в HyDE кодируется как документ.
- AB: сборка Python без GIL, `rsync --partial`.
- B, O: недостающий `import os`, пояснение к DETACH PARTITION.
- U: MCP поддерживают и другие вендоры.

## Полное выравнивание с учебником ШАД

Третий проход шёл не по выборочным местам, а по всем 25 главам учебника. Из каждой главы взяты все выделенные жирным термины — это собственный список ключевых понятий учебника. Затем скрипт проверил, есть ли каждое понятие в теории, терминах и вопросах блоков, на которые ложится глава. Всё, чего не было, дописано со ссылкой на главу, а формулы сверены с текстом учебника (дисперсии Xavier и He, критерий Джини, канонические функции связи GLM, связь шума Лапласа с MAE и гауссовского априорного распределения с L2, ISTA).
