# Styding-MLE-AI

Обучение MLE и AI до сеньора.

## Тренажёр AI-инженера

Одностраничный тренажёр: квиз по 19 блокам плюс FAQ с терминами. Всё содержание вшито в HTML, внешних запросов страница не делает, интернет для работы не нужен.

Открыть: `open ai_engineer_training.html`.

## Что где лежит

| файл | что это |
|---|---|
| `ai_engineer_training.html` | собранная страница, 105 вопросов, 20 разделов, 174 термина |
| `training/quiz_*.json` | источники вопросов: core, mid_senior, senior_agents |
| `training/faq_*.json` | источники разделов FAQ с терминами |
| `training/tracks.json` | шесть треков и привязка блоков к ним |
| `tools_build_training_artifact.py` | пересборка HTML из источников |
| `tools_check_training_artifact.py` | проверка собранной страницы |

Треки: замеры и доказательства, данные, модели, поиск и агенты, прод и инфраструктура, ремесло и ML-канон.

## Как менять содержание

Править нужно json в `training/`, а не HTML. Дальше:

```
python3 tools_build_training_artifact.py
python3 tools_check_training_artifact.py --sources training/*.json
```

Сборщик заменяет в странице литералы `QUIZ_DATA`, `FAQ_DATA`, `TRACKS` и обновляет счётчики в шапке. Проверялка сверяет число вопросов и разделов с источниками, следит за дословностью текста, гоняет `node --check` по встроенному JS и проверяет тёмную тему с `prefers-reduced-motion`. Для JS-части нужен `node`, без него этот пункт пропускается.

Новый блок вопросов требует записи в `tracks.json`: без назначенного трека сборка падает с перечислением осиротевших идентификаторов.
