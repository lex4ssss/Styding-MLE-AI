# Styding-MLE-AI

Обучение MLE и AI до сеньора.

## Тренажёр AI-инженера

Одностраничный тренажёр: экзамен по 23 блокам, справочник с теорией, практикой и бизнес-кейсами, библиотека материалов. Всё содержание вшито в HTML, внешних запросов страница не делает, интернет нужен только для перехода по ссылкам библиотеки.

Открыть: `ai_engineer_training.html` в браузере.

Три режима: экзамен с разбором каждого ответа, справочник с поиском по разделам, библиотека с маршрутом обучения.

## Что где лежит

| файл | что это |
|---|---|
| `ai_engineer_training.html` | собранная страница: 148 вопросов, 24 раздела, 227 терминов, 200 материалов |
| `template.html` | шаблон страницы: вёрстка, стили и логика, данные подставляются в `__DATA__` |
| `training/quiz_*.json` | источники вопросов: core (A–H), mid_senior (I–T), senior_agents (U–W) |
| `training/faq_*.json` | источники разделов справочника: лид, теория, практика, бизнес, термины, ловушки, задание, материалы |
| `training/tracks.json` | шесть треков и привязка блоков к ним |
| `training/library.json` | маршрут обучения, видео по блокам, полный каталог источников |
| `tools_build_training_artifact.py` | сборка страницы из шаблона и источников |
| `tools_check_training_artifact.py` | проверка собранной страницы |

Треки: замеры и доказательства, данные, модели, поиск и агенты, прод и инфраструктура, ремесло и ML-канон.

## Блоки

A замеры и статистика · B эталон, данные, утечки · C промпт, схема ответа, декодинг · D VLM и вход · E инференс и деплой · F RAG, эмбеддинги, дообучение · G оценка качества и судья-LLM · H прод, CI, безопасность, деньги · I разбор и декомпозиция задач · J NLP · K зоопарк моделей · L бинарная классификация · M эксперимент по кнопке и Optuna · N шум, нормализация, основы DS · O SQL и хранение данных · P метрики и гиперпараметры · Q прогнозирование и табличный ML · R CV, OCR и мультимодальный RAG · S эмбеддинги, трансформеры, внимание · T математика под капотом · U агенты и tool use · V продвинутый RAG и его метрики · W архитектура модели и сэмплирование · Z личная гигиена

## Как менять содержание

Править нужно json в `training/` и `template.html`, а не собранный HTML. Дальше:

```
python tools_build_training_artifact.py
python tools_check_training_artifact.py
```

Сборщик подставляет данные в шаблон и пишет `ai_engineer_training.html`, счётчики в шапке считаются на клиенте. Проверялка сверяет число блоков, вопросов и разделов с источниками, ищет дубли вопросов и битые индексы ответов, требует у каждого раздела лид, термины, ловушки и задание, проверяет схему ссылок и размер страницы.

Новый блок требует записи в `tracks.json`: без назначенного трека сборка падает с перечислением осиротевших идентификаторов.

## Библиотека

`training/library.json` содержит маршрут из шести этапов, 24 видео на русском и английском с привязкой к блокам и полный каталог источников: awesome-artificial-intelligence целиком, программа курса Visual GenAI (12 лекций и 7 практик) и учебник MIT 6.042J.
